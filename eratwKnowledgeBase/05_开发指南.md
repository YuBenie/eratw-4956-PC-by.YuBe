# eraTW 开发指南

> 基于对 ERB 代码（口上・メッセージ関連除外）的阅读总结

## 1. 如何添加新指令

### 步骤 1：创建指令文件

在 `ERB/コマンド関連/COMF/` 或 `COMF/日常系/` 下创建 `COMF{编号} {名称}.ERB`：

```erb
;-------------------------------------------------
;指令名称
;日常系指令 等级1
;-------------------------------------------------
@COM{编号}_DISPLAY
#FUNCTIONS
; 动态指令名显示（可依据状态变色改字）
; 例如：IF 条件 → TEMP_COM_DISPLAY_COLOR = C_GRAY

@COM_ABLE{编号}
; 可用性判定
; RETURN 1 = 可用，RETURN 0 = 不可用
RETURN 1

@COM{编号}
; 指令主逻辑
; 消耗行动力/时间
; 计算效果、输出文本
RETURN 1
```

### 步骤 2：USERCOM 自动生效

指令创建后会自动被 `USERCOM.ERB` / `QOL_USERCOM.ERB` 的遍历（0~800）发现，无需额外注册。

### 步骤 3：指令编号选择

- 270~299：自定义口上指令（KX 系列）
- 300~499：日常系指令
- 🚫 避免与已有编号冲突

## 2. 如何添加自定义指令（fromEN 方式）

参考 `ERB/fromEN/Custom_Commands/`：

```erb
; 命令名
@KOJO_XXX_COM_NAME_KX_Y
    RESULTS = 指令名

; 使用条件
@KOJO_XXX_COM_ABLE_KX_Y
    RETURN 1

; 执行内容
@KOJO_XXX_COM_KX_Y
    RETURN 1

; 文本
@M_KOJO_XXX_MESSAGE_COM_KX_W
    RETURN 1
```

## 3. 如何修改事件

### 每日事件

- 早晨：`BEFORETRAIN.ERB`（来訪判定时读取）
- 回合结束：`EVENTTURNEND.ERB`
- 调教结束：`AFTERTRA.ERB`（@EVENTEND）

### 每日随机事件（デイリーイベント/）

```erb
; 创建 DAILY_EV{编号} {名稱}.ERB
; 参照 DAIRY_EV0~34 的现有实现
; 在 DAILY_VARS.ERH 中注册事件
```

### 外出事件（お出かけイベント/）

```erb
; 创建 GO_OUT_EV{编号} {名稱}.ERB
; 参照 GO_OUT_EV00~09 的实现
; 在 お出かけイベント.ERB 中注册
```

## 4. 如何创建 DLC

参考 `ERB/DLC/` 的现有实现模式：

```erb
; DLC 开关变量（在 DLC.ERH 中定义）
; IF DLC开关 && 条件
;     执行DLC逻辑
; ENDIF
```

### 典型 DLC 结构

1. **常量定义**：`DLC.ERH` 中定义开关变量
2. **入口函数**：`DLCEVENT.ERB`（每日调用）、`OPTIONDLC.ERB`（选项设置）
3. **主逻辑**：独立 ERB 文件
4. **显示**：在 USERCOM/菜单中按条件显示

## 5. QOL 开发规范

QOL 的设计原则是**不修改原文件**，通过覆盖/增强实现：

```erb
; 替换原始 USERCOM 逻辑
CALL QOL_SHOW_USERCOM

; 扩展指令过滤
CALL KOJO_CHECK(TARGET, "COM_BLOCKED",,LOCAL)

; 动态指令名接口
TEMP_COM_DISPLAY_NAME '= GETMETHS(@"COM{LOCAL}_DISPLAY", "Null")
```

### QOL 常见模式

| 模式 | 用途 |
|------|------|
| 覆盖显示函数 | 增强 UI 显示 |
| 添加过滤条件 | 新增指令分类 |
| 调用扩展接口 | 使用现有扩展点 |
| TRYCALLFORM | 安全调用可选功能 |

## 8. 编码规范要点

1. **命名**：功能名拼音/日文/中文混合，保持一致
2. **注释**：分节注释标明用途
3. **缩进**：Tab 缩进，块级结构对齐
4. **SIF 优先**：单行条件用 SIF
5. **返回约定**：`RETURN 1`=成功，`0`=正常，`-1`=失败
6. **安全调用**：动态函数用 TRYCALLFORM 包裹
7. **字符串**：`'=` 连接，`@""` 格式化，`%变量%` 插值
8. **数组**：动态数组用 `#DIM DYNAMIC`，存档优先用 `#DIM SAVEDATA`

## 9. 性能优化建议

- `CURRENTREDRAW()` 检查后使用 `REDRAW 0` 批量绘制
- 大循环中避免显示操作（`DEBUGPRINTFORML` 不影响性能）
- 动态变量（`#DIM DYNAMIC`）比全局变量开销小
- 用 `VARSIZE()` 获取数组上限而非硬编码
