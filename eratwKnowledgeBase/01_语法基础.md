# ERB 语法基础

> 基于对 ERB 文件夹实际代码的阅读总结

## 1. 文件类型

| 扩展名 | 用途 |
|--------|------|
| `.ERB` | ERB 脚本文件（主逻辑） |
| `.ERH` | 头文件（常量/变量声明） |
| `.ERD` | 数据文件（二进制/数组数据） |

## 2. 注释

```erb
; 行注释（分号开头）
```

## 3. 标签/函数定义

```erb
@LABEL_NAME                     ; 无参数
@FUNC_NAME(ARG)                 ; 单参数
@FUNC_NAME(ARGS, ARG, ARG:1=0) ; 多参数 + 默认值
#FUNCTIONS                      ; 函数声明（自动 RETURN）
#FUNCTION                       ; 单值返回函数
```

## 4. 变量声明

```erb
#DIM 变量名          ; 整数变量
#DIMS 变量名         ; 字符串变量
#DIM CONST 常量 = 值  ; 常量
#DIM DYNAMIC 变量名   ; 动态变量
#DIM SAVEDATA 变量名  ; 存档持久化变量
#DIM CHARADATA 变量名 ; 角色持久化变量
#DIM GLOBAL 变量名    ; 全局变量
#LOCALSIZE N         ; 局部整数数组大小
#LOCALSSIZE N        ; 局部字符串数组大小
VARSET 变量           ; 清空变量数组
```

## 5. 变量体系

### 局部变量
```erb
LOCAL       ; 整数 (从0开始)
LOCAL:1     ; 一维数组
LOCAL:1:1   ; 二维数组
LOCALS      ; 字符串
LOCALS:1    ; 字符串数组
```

### 角色/全局变量（核心）

| 前缀 | 含义 | 维度 | 示例 |
|------|------|------|------|
| `CFLAG:` | 角色标志（存档） | `[角色:属性]` | `CFLAG:MASTER:現在位置` |
| `TFLAG:` | 临时标志 | `[属性]` | `TFLAG:193` |
| `FLAG:` | 系统标志 | `[属性]` | `FLAG:70` |
| `BASE:` | 基础数值 | `[角色:属性]` | `BASE:MASTER:体力` |
| `MAXBASE:` | 最大基础值 | `[角色:属性]` | `MAXBASE:ARG:気力` |
| `ABL:` | 能力值 | `[角色:属性]` | `ABL:MASTER:話術技能` |
| `TALENT:` | 特质 | `[角色:属性]` | `TALENT:恋慕` |
| `MARK:` | 刻印 | `[角色:属性]` | `MARK:不埒刻印` |
| `TCVAR:` | 角色临时变量 | `[角色:属性]` | `TCVAR:TARGET:発情` |
| `TEQUIP:` | 临时装备 | `[角色:属性]` | `TEQUIP:TARGET:体位` |
| `SOURCE:` | 情绪源 | `[角色:属性]` | `SOURCE:歓楽` |
| `EXP:` | 经验值 | `[角色:属性]` | `EXP:MASTER:会話経験` |
| `CUP:` | 快感累积 | `[角色:属性]` | `CUP:ARG:快Ｃ` |
| `PALAM:` | 快感参数 | `[角色:属性]` | `PALAM:CHARA:0` |
| `EX:` | 扩展数据 | `[角色:属性]` | `EX:LOCAL:膣内精液` |
| `ITEM:` | 物品数量 | `[物品ID]` | `ITEM:簡易プール` |
| `EQUIP:` | 装备 | `[角色:属性]` | `EQUIP:0` |
| `STAIN:` | 污渍 | `[角色:部位]` | `STAIN:MASTER:0` |
| `DOWNBASE:` | 降低基础值 | `[角色:属性]` | `DOWNBASE:気力` |
| `STcvar:`/`STequip:`/`SPalam:`/`SaveEX:` | 存档用临时变量 | - | - |

## 6. 控制流

```erb
; 单行条件
SIF 条件
    语句

; 多行条件
IF 条件1
    语句
ELSEIF 条件2
    语句
ELSE
    语句
ENDIF

; 选择分支
SELECTCASE 表达式
    CASE 值1, 值2
        语句
    CASE 0 TO 5
        语句
    CASE IS < 400
        语句
    CASEELSE
        语句
ENDSELECT

; 循环
FOR LOCAL, 0, 800
    语句
    CONTINUE    ; 跳过本次
    BREAK       ; 跳出循环
NEXT

; 跳转
GOTO LABEL
$LABEL
```

## 8. 函数调用

```erb
CALL 函数名                    ; 无参调用
CALL 函数名(参数1, 参数2)       ; 带参调用
CALLFORM 动态函数名{变量}        ; 动态函数名
TRYCALLFORM 函数名{}()          ; 安全调用（不存在则跳过）
TRYCCALLFORM 函数名()           ; 带 CATCH 的调用
    [主逻辑]
CATCH
    [异常处理]
ENDCATCH
GETMETH(@"函数名", "默认值")    ; 获取函数返回值
EXISTMETH(@"函数名")            ; 检查函数是否存在
RETURN 值       ; 返回
RETURNF 值      ; 返回（#FUNCTION 自动清理）
```

## 9. 内置函数

```erb
; 数学
RAND:100                ; 随机 0~99
MAX(a, b) / MIN(a, b)   ; 最大/最小
ABS(x) / SQRT(x)        ; 绝对值/平方根
LIMIT(x, min, max)      ; 限制范围
INRANGE(x, min, max)    ; 范围检测（含边界）

; 位运算
GETBIT(变量, 位)         ; 读位
SETBIT 变量, 位          ; 写位
CLEARBIT 变量, 位        ; 清除位

; 字符串
STRLENS(str)             ; 长度
STRCMP(str1, str2)       ; 比较
STRCOUNT(str, sub)       ; 子串计数
GROUPMATCH(x, v1, v2..)  ; 多值匹配

; 渲染
GETCOLOR()               ; 前景色
GETBGCOLOR()             ; 背景色
CLIENTWIDTH()            ; 窗口宽
CLIENTHEIGHT()           ; 窗口高
MOUSEX() / MOUSEY()     ; 鼠标坐标
CURRENTREDRAW()          ; 当前重绘状态

; 游戏相关
GETTIME()                ; 系统时间戳
GET_TARGETNUM()          ; 目标数
GET_MONTH()              ; 游戏内月份
CHECK_CHARA(id, type)    ; 角色类型检查
AT_HOME(chara)           ; 是否在家
BATHCHECK(pos)           ; 是否有浴室
OPENPLACE(pos)           ; 是否开阔场地
VARSIZE("SOURCE")        ; 获取变量数组大小
```

## 10. 显示命令

```erb
PRINTL            ; 打印 + 换行
PRINTW            ; 打印 + 等待
PRINTPLAIN        ; 纯文本
PRINTS 变量       ; 打印字符串变量
PRINTFORML        ; 格式化打印 + 换行
PRINTFORMC        ; 格式化 + 颜色
PRINTC            ; 带颜色打印
PRINTBUTTON       ; 按钮
PRINTBUTTON_EX("文本", 值, 启用) ; 高级按钮

SETCOLOR 颜色值    ; 设置前景色
RESETCOLOR        ; 重置颜色
CLEARLINE n       ; 清除 n 行
REDRAW 0/1        ; 禁止/允许重绘

; HTML 渲染
HTML_PRINT html, mode
HTML_PRINTC html
HTML_PRINTBUTTONC "文本", 值, "颜色"

; 输入
INPUT             ; 数字输入
INPUTS            ; 字符串输入
INPUT -1, 1       ; 鼠标/任意键输入

; 字符串格式化
@"文本{变量}更多"   ; @"" 语法
%変数%             ; %...% 插值
```

## 12. 重要 TFLAG 约定

| TFLAG | 含义 |
|-------|------|
| TFLAG:3 | SELECTCOM 的备份值 |
| TFLAG:100 | 自动执行标记 |
| TFLAG:192 | 口上结果覆盖标记（-1=取消指令） |
| TFLAG:193 | 指令结果（1=大成功 0=普通成功 -1=失败 -2=强制退出） |
| TFLAG:信頼度管理 | 好感度变化标记 |
| TFLAG:苦痛刻印取得 / 時姦刻印取得 | 刻印获取标记 |
| TFLAG:23 | 快乐刻印获取等级 |
