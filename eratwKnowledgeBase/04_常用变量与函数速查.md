## 2. 常用函数速查

### 条件/判定
```
COM_ABLE{N}()        ; 指令是否可用
GLOBAL_COMABLE2(N)   ; 全局指令可用性（QOL）
QUICKFILTER(N)       ; 指令快速过滤
IS_COM_KOJO(N)       ; 是否口上指令
IS_DATING_WITH_PLAYER(TARGET) ; 是否与玩家约会中
CHK_DATENOW(值)      ; 约会日期检查
GET_SUCCESS_RATE()   ; 获取成功率
REVEAL_YOUKAI(TARGET) ; 揭示妖怪真身
KIGEN_CHANGE(角色, 值) ; 心情变化
SET_SLEEP(标志,角色,值) ; 睡眠设置
```

### 数据处理
```
VARSET 变量           ; 清空数组
ARRAYCOPY "源","目标"  ; 数组复制
DIC_CONTAINSKEY(变量, 键) ; 字典是否含键
DIC_GET(变量, 键)      ; 获取字典值
DIC_SET(变量, 键, 值)  ; 设置字典值
TOSTR(值) / TOINT(字符串) ; 类型转换
MIN(a,b) / MAX(a,b)   ; 数学
LIMIT(值,min,max)     ; 限制
RAND:上限             ; 随机
NOW_PERIOD()          ; 获取当前时代/周期
```

## 5. 常见代码模式

### 成功判定模式
```erb
LOCAL = RAND:100
LOCAL:1 = MIN(90 + GET_SUCCESS_RATE() / 5, 99)
LOCAL:2 = 5  ; 大成功阈值
IF LOCAL < LOCAL:2
    TFLAG:193 = 1    ; 大成功
ELSEIF LOCAL >= LOCAL:1
    TFLAG:193 = -1   ; 失败
ELSE
    TFLAG:193 = 0    ; 普通成功
ENDIF
```

### 口上检查模式
```erb
CALL KOJO_CHECK(TARGET, "COM_BLOCKED",,LOCAL)
SIF RESULT
    RETURN 0
```

### 安全调用模式
```erb
TRYCALLFORM COM_ABLE{LOCAL}
SIF !RESULT
    CONTINUE
```

### 存档变量备份模式
```erb
IF SaveDataInTrain
    ARRAYCOPY "TFLAG", "STflag"
    CALL INIT_NG_OR_LOAD
    BEGIN TRAIN
ENDIF
