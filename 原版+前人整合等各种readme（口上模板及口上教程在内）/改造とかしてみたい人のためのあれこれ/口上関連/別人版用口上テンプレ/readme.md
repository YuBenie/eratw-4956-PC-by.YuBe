## 入口函数（イベント.ERB）
--建议优先修改此处文件--
```erb
;### 口上存在判定
@M_KOJO_KX_X2(ARG)
RESULTS = _XXX     ; 替换为唯一标识
RESULTS:1 = ＸＸＸ  ; 口上选择时显示的名称
```

## 「記入チェック」开关机制

- 外层 `LOCAL = 0` → 改为 1 启用该命令口上
- 内层 `LOCAL:1 = 0` → 改为 1 启用该小分支
- 没改到 1 的地方会跳过，不显示台词

## 制作步骤

1. 全局替换 `KX` → 角色编号，`XXX` → 口上名称
2. 修改 `イベント.ERB` 入口：`RESULTS` 和 `RESULTS:1`
3. 在各文件中，逐条命令将 `LOCAL = 0` → `LOCAL = 1` 表示启用口上，不修改则不会应用在游戏里
4. 根据需要填写各种不同的模板文件
5. 按 `ライセンステンプレ.txt` 添加授权信息(可选,仅发布时再考虑)
6. 本仓库仅用作模板，若对教程有需求请移步至(____占位____)
